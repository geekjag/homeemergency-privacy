Privacy Policy for Home Emergency

Last updated: 08th July 2025

Overview

Home Emergency is designed to create a local emergency alert network between devices on the same WiFi network. We are committed to protecting your privacy.

Data Collection

This app does not collect, store, or transmit any personal data to external servers. All communication happens locally on your WiFi network.

Information We Use Locally

  • Device name (set by you for identification)
  • Local IP address (for network communication)
  • Emergency messages (sent only to local network devices)

Permissions Used

  • Network Access: To communicate with devices on your local WiFi network
  • Notifications: To display emergency alerts
  • System Overlay: To show emergency alerts on screen
  • Boot Receiver: To automatically start the emergency service

Data Sharing

No data is shared with third parties, external servers, or cloud services. All communication is local to your network.

Data Storage

The app only stores your device name and app preferences locally on your device. No data is backed up to cloud services.
